# سناریوی دمو NAVA

## آماده‌سازی

1. `alembic upgrade head`
2. `python scripts/seed_demo.py`
3. برای پاسخ deterministic در دمو، `AI_CHAT_PROVIDER=mock` را تنظیم کنید.
4. آدرس چاپ‌شده‌ی seed را در مرورگر باز کنید.

## سناریوی ۳ تا ۵ دقیقه‌ای

1. درباره‌ی «کتونی مشکی» سؤال کنید و قیمت/موجودی را بپرسید.
2. با عبارت «همون محصول» یک سؤال پیگیری بپرسید.
3. درباره‌ی ارسال یا مرجوعی سؤال کنید تا FAQ/RAG دیده شود.
4. از فروشنده بخواهید محصول را به سبد اضافه کند و تعداد را بررسی کنید.
5. checkout و اطلاعات مشتری را تکمیل کنید.
6. شماره سفارش، اقلام، مبلغ و وضعیت را نمایش دهید.
7. با حساب فروشنده وارد `/dashboard` شوید و سفارش و مکالمه را بررسی کنید.
8. وضعیت سفارش را از `pending` به `confirmed` تغییر دهید.

در مسیر API مهمان، token را با header `X-Guest-Token` حفظ کنید. برای retry سفارش
از `Idempotency-Key` تصادفی استفاده کنید. فرم عمومی فروشگاه همین token را در
`localStorage` نگه می‌دارد و cart/checkout را بدون login انجام می‌دهد.

## چک‌لیست اسکرین‌شات

`/public/stores/{id}`، کاتالوگ/محصول، چت، سبد، checkout، تأیید سفارش، داشبورد، سفارش‌ها، مکالمه‌ها و دانشنامه.
