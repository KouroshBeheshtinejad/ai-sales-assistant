# Security Policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in public issues, discussions,
or pull requests. Use GitHub's private vulnerability reporting for this
repository:

https://github.com/KouroshBeheshtinejad/ai-sales-assistant/security/advisories/new

Include affected versions or commits, impact, reproduction steps, and any
suggested mitigation. Avoid including real customer data, credentials, or
unredacted production logs. The maintainer will coordinate a fix and disclosure
when reasonably possible; no response-time guarantee is made by this policy.

If private vulnerability reporting is unavailable, contact the repository
owner through their GitHub profile and request a private security channel.

## Supported versions

Security fixes are currently considered for the latest version on the default
branch. No separate long-term-support branches are promised.
